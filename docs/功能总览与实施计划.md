## 五、关键规则与待确定事项

| 项目       | 统一规则                                                                                               |
| ---------- | ------------------------------------------------------------------------------------------------------ |
| 微信身份   | 微信绑定、头像昵称、真实姓名、手机号必填；头像不作为核验底照                                           |
| 有效打卡   | 启用中的项目、有效成员、适用排班、审核底照、定位、活体及本人上传现场照片全部满足；凭证只用一次         |
| 定位与打卡 | 无独立定位检测按钮；点击打卡自动定位，范围内才继续核验；范围外直接拒绝且不生成考勤记录，定位失败不放行 |
| 打卡安排   | 默认上、下班两次；上级设置下级，个人 > 班组 > 项目；调整最早次日生效，历史不改写                       |
| 工时       | 北京时间、同日上下班成对累计；中途签到不增加工时；不自动扣午休，分段班按各段计算                       |
| 异常与应勤 | 未到时点及未来日期不提前判异常；休息日、入场前、退场后不计应勤                                         |
| 出勤率     | 实勤按有有效考勤的工作日计；实勤÷应勤，应勤为零显示不适用                                              |
| 补卡       | 只能审批范围内下级；禁止未来、无排班及重复申请；批准与重算同事务，保留原始记录                         |
| 历史与报表 | 按当时成员归属和排班统计；同人跨项目分别计数；页面与 Excel 同口径                                      |
| 文件权限   | 服务端限制下载范围；报表不含人脸原图及完整敏感字段                                                     |
