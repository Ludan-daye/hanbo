# 二级班组长：功能与验收清单

适用版本：`main`，业务代码基线 `5964716`。核对日期：2026-11-17。

本清单供协作者测试二级人员功能。**二级＝班组长，只管理获授权班组；三级＝项目管理员。** 班组长保留本人项目、任务、打卡及补卡功能。

以下用例均为**待协作者验收**，已有代码和自动化检查不代表手机验收通过。整体进度见 [功能总览与实施计划](功能总览与实施计划.md)。

## 二、首页、人员与权限

入口：班组长首页、工作台。

| 编号 | 功能／操作 | 预期结果 |
| --- | --- | --- |
| TL01 | 二级登录，进入首页；切换本人获授权的班组 | 显示对应项目、班组、在场工人、今日出勤、缺卡及待审批；切换后不混入上一班组数据 |
| TL02 | 搜索本班工人姓名、手机号，查看详情 | 可找到对应人员，工种和联系方式正确；不显示范围外人员 |
| TL03 | 用班组长 A 访问班组 B 的任务、人员、模板、考勤、安全、日报和导出；开发者同时改请求中的班组／项目 ID | 页面与服务端均限制访问，不返回范围外数据或文件 |
| TL04 | 工人访问管理入口；班组长尝试自审补卡、审核同级及变更全局信用规则 | 不提供越权操作；直接请求也被拒绝。兼任账号按实际授权测试，不能当作“纯二级”账号 |
| TL05 | 班组长打开“我的项目／我的任务／我的考勤／补卡申请” | 个人功能可用，记录属于本人；本人打卡要求由上级配置 |

## 三、工作安排与临时用工

入口：首页 → 工作安排。临时工从登录页“临时用工”进入。

| 编号 | 功能／操作 | 预期结果 |
| --- | --- | --- |
| TL06 | 新建安排，填写工作内容，从“安排人员”勾选本班工人并发布 | 人员来自数据库中的本项目、本班组有效工人；保存后重进仍存在，工人“我的任务”可见 |
| TL07 | 搜索、勾选多人、取消勾选；尝试安排其他班组、暂停或退场人员 | 已选名单正确、不重复；不可安排无效或范围外人员，后端同样拦截 |
| TL08 | 检查默认时间，修改开始／结束日期和时间；工种、备注留空 | 默认采用适用排班，可调整；选填项可空。结束不晚于开始、已过期或超过 24 小时均拒绝；合法跨夜安排可保存 |
| TL09 | 修改未开工安排，追加人员，移除未开工人员，再尝试移除已开工人员 | 修改持久化，追加不重复；已开工人员不能直接移除；时间变更后旧待用邀请码作废 |
| TL10 | 搜索历史模板，使用“套用模板”或“套用此安排”，调整日期后发布 | 创建新任务，原任务不变；临时工及已离场人员不自动带入，提示重新选择／邀请 |
| TL11 | 完成或取消任务，再用该任务未使用的邀请码加入 | 状态保存，待用码失效；历史成员和考勤保留，不按计划时长自动补出实际工时 |
| TL12 | 为临时工填写真实姓名、手机号，生成并复制邀请码 | 生成六位数字，前导零保留；关联当前项目、班组和任务；有效期最多 24 小时且不超过任务结束时间 |
| TL13 | 对应临时工输入邀请码，完成登记及底照录入 | 姓名、手机号须匹配；加入正确项目、班组和任务，仅增加工人身份；不能跳过必填资料或底照，刷脸打卡仍须底照审核通过 |
| TL14 | 使用姓名／手机号不符、过期、撤销、已消费的码；连续输入错误码 | 不绑定错误人员，不重复入场；明确提示失败，连续尝试受服务端限流 |
| TL15 | 已有档案工人接受新项目邀请；另测同项目其他班组的工人 | 保留原档案、底照及权限；不重复建人、不自动转组、不自动升为班组长 |
| TL16 | 临时工按任务开工、完工；班组长查看记录并确认退场 | 实际时间和工时可查；必须已完工且没有其他未结束任务才可退场，原档案与考勤留存 |

任务计时使用新入场临时工测试。原有常规项目成员被安排任务后仍按原排班打卡，不额外生成一套重复计工记录。

## 四、打卡安排、考勤与补卡

入口：首页 → 打卡安排／查看班组考勤／补卡审批；工人端配合实际打卡。

| 编号 | 功能／操作 | 预期结果 |
| --- | --- | --- |
| TL17 | 给授权下级设置打卡次数、时间、宽限和工作日；恢复继承 | 基础默认两次，可新增／删除打卡点；个人优先于班组，班组优先于项目；恢复继承后使用上级规则 |
| TL18 | 设置次日起生效的新安排，查看今日与历史记录 | 新规则不改写今日和历史；禁止给本人、同级、上级或范围外人员设置 |
| TL19 | 切换班组日报、周报、月报，打开工人逐日明细 | 项目、班组、人员和日期正确；未到打卡时点不提前计缺卡，休息日、入场前、退场后不计应勤 |
| TL20 | 工人申请补卡，班组长通过一条、驳回一条，再查看历史 | 仅处理授权下级；状态、意见及审批时间保存；批准后考勤与报表重算，驳回不增加工时 |
| TL21 | 提交未来、重复及不匹配排班的补卡；重复审批已处理申请 | 请求被拒绝或返回已处理状态，不新增重复考勤；班组长不能审批本人申请 |
| TL22 | 手机执行范围外、定位失败、缺照片、未确认交底、活体失败，再完成一次正常流程 | 前四项不能进入有效刷脸提交；活体失败不能生成有效考勤。正常流程：范围内 GPS → 现场照片 → 本次安全交底 → 活体与底照比对 → 入库 |

工时新增项需**新版 API＋数据库迁移**。项目类型、午休、加班起点由有项目配置权限的管理人员准备，班组长验收结果；不额外授予二级项目配置权限。

| 编号 | 功能／操作 | 预期结果 |
| --- | --- | --- |
| TL23 | 普通工作：有效区间 09:00–18:00，项目午休 12:00–13:00，加班起点 18:00 | 正常 8 小时，加班 0；以有效打卡分钟计算，**不折算工日** |
| TL24 | 独立加班 18:30–20:00；另测连续工作 09:00–20:00，规则同 TL23 | 前者加班 1.5 小时；后者正常 8、加班 2，总计 10 小时；无需另提加班审批，重叠区间不重复累计 |
| TL25 | 零星／临时任务实际 09:00–12:00，计划时间另设；跨夜任务 22:00–次日 02:00，无午休扣除 | 前者实际 3 小时；后者按北京时间分成两天各 2 小时，正常／加班类别按各日有效规则判断；计划时长不作实际工时 |
| TL26 | 临时任务或独立加班已有开工但缺完工，申请完工补卡并由上级审批 | 未完工标记待核实，不预估整段工时；通过后按实际区间重算，跨夜同步两日；临时任务缺开工不自动补算 |
| TL27 | 查询无历史工时规则的旧记录、更新规则前后的记录 | 无规则记录保留未分类工时，不反推历史加班；新规则按生效日期应用，页面和报表分钟口径一致 |

## 五、安全管理与安全信用

入口：首页 → 班组安全 → 安全交底／待整改／按日记录；信用入口为“人员违规与安全信用”。

| 编号 | 功能／操作 | 预期结果 |
| --- | --- | --- |
| TL28 | 发布当日安全交底，工人确认；查看已确认和待确认名单 | 仅本班可见，保留原文、发布人与工人确认记录；已发布内容不直接覆盖，补充内容另发 |
| TL29 | 工人确认本次打卡交底后，新增交底或超过确认凭证 15 分钟，再尝试打卡 | 要求重新确认；其他人员／项目／打卡时段的凭证不能复用 |
| TL30 | 登记现场或关联工人的隐患，次日查看“待整改”，填写措施并关闭 | 未整改事项跨日期保留，关闭后从待整改移除，按日历史仍可查；隐患关闭本身不自动变成信用扣分 |
| TL31 | 给本班工人登记违规类别、程度、时间、说明及 1–5 张凭证照片 | 人员与凭证校验通过后进入待审核；空字段／无凭证拒绝；未复核不扣分，重复提交同一事件不重复累计 |
| TL32 | 三级项目管理员复核；另测记录人自审、同级互审或审核本人违规 | 由范围内且高于记录人的上级复核；后三种拒绝。单独测试一般／严重／重大事件：初始 100 分分别变为 95／90／80 |
| TL33 | 同一工人档案分别在公司 A、B 产生已确认违规，查看两处榜单及明细 | 共用一份安全分与累计次数；各班组／项目只看授权范围事件，不能查看其他公司的事件说明或照片；不按同名人员合并 |
| TL34 | 工人违规后累计 10 个无违规实际工作日；加入同日跨项目、停工日和缺完工记录 | 满足条件恢复 5 分，上限 100；同日只计一次，停工日及未完成有效区间不计；新的确认违规重置累计 |
| TL35 | 工人就本人记录申诉，上级驳回或撤销违规，再查看榜单与分数 | 处理理由和历史保留；驳回保持原结果，撤销后重算分数及次数；班组长不能自行终审本人登记的记录 |

信用初始 100、范围 0–100；扣分依据已确认行为。健康申报、保险及银行卡不参与信用计算。项目工作评分与安全信用分分别展示。

## 六、班组日报与 Excel

入口：首页 → 班组日报；查看班组考勤 → 月报 → 导出。

| 编号 | 功能／操作 | 预期结果 |
| --- | --- | --- |
| TL36 | 查看指定日期班组日报，核对任务、临时人员、实际出勤、工时、交底及隐患 | 数据来自实际业务；取消任务单列，不以计划人数／计划时长代替实际出勤与工时 |
| TL37 | 保存日报，退出重进查看保存内容；补卡或整改后查看最新汇总并重新保存、复制 | 保存快照可回读；查看实时汇总不自动覆盖快照，重新保存才更新；复制文本与所选汇总一致 |
| TL38 | 查看月报的项目、班组、人员与逐日记录，核对项目评分及安全分 | 仅本班授权范围；正常／加班／未分类分列，含项目类型与临时标记；未评分显示“未评分”，0 分按 0 展示；二级可查看但不能代替三级录入项目评分 |
| TL39 | 生成并打开月度 Excel，核对六张工作表 | 包含“月度汇总、每日明细、补卡与异常、安全记录、打卡位置、统计说明”；与同范围、同时间、同数据状态的页面对账一致 |
| TL40 | 补卡、更正评分或撤销违规后重新生成 Excel，再打开旧文件；尝试越权下载 | 新版本反映更正，旧文件不被覆盖；他人或其他班组文件拒绝下载；报表不含完整身份证、银行卡、健康资料、人脸原图 |
| TL41 | 核对实际打卡与补卡的位置；手机打开并分享 Excel | 实际打卡含位置、时间与精度，补卡不伪造 GPS；打卡点不表示连续路线；手机文件可正常打开、分享 |
